# Scripts auxiliares

Estos scripts se ejecutan desde la raiz del proyecto:

```powershell
python .\scripts\exploracion_dinamica.py
python .\scripts\verificar_roles.py
```

`exploracion_kore.py` contiene la grabacion manual generada con Playwright Codegen y sirve como referencia.

El punto de entrada principal sigue siendo:

```powershell
python .\change_badge.py
```
