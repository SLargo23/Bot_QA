# Bot Kore

## Installation

1. Clone the repository or download the project files.
2. Navigate to the project folder:
   ```bash
   cd "path\to\Bot_K"
   ```
3. Create and activate a Python virtual environment:
   - On Windows PowerShell:
     ```bash
     python -m venv venv
     .\venv\Scripts\Activate.ps1
     ```
   - On Windows Command Prompt:
     ```bash
     python -m venv venv
     .\venv\Scripts\activate.bat
     ```
4. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```



## Execution

1. Run the bot:

   - First set_ambient (Preproduction or Production):
     ```bash
     set_ambient= 0 (Production)
     set_ambient= 1 (Preproduction)
     ```
   - Execute Python- Playwright BOT
     ```bash
     python change_badge.py 
     ```
2. Verify the bot starts successfully and follow any console instructions.

## Notes

- Update configuration files if required before running.
